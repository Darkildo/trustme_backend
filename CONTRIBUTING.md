# Участие в разработке

Pull request'ы, сообщения об ошибках и предложения приветствуются.

## Перед началом

- **Уязвимости** — не через issues, а приватно, по [SECURITY.md](SECURITY.md).
- **Ошибки и предложения** — через issues. Для ошибки укажите версию, бэкенд
  доставки (sled или JetStream), шаги воспроизведения и логи без
  персональных данных.
- **Крупные изменения** (протокол, схемы, формат хранилища) сначала обсудите
  в issue: схема `schemas/` — контракт с клиентами на других языках.

## Лицензия и CLA

Код распространяется по PolyForm Strict 1.0.0 с дополнительными
разрешениями из [LICENSING.md](LICENSING.md). Изменять код ради pull
request'а в этот репозиторий разрешено.

Чтобы вклад можно было принять, автор подписывает
[Contributor License Agreement](CLA.md) один раз, при первом pull request'е.
Бот попросит оставить в PR комментарий:

```
I have read the CLA Document and I hereby sign the CLA
```

Подпись распространяется на все будущие вклады. Если вы вносите вклад от
имени компании, свяжитесь с правообладателем до подписания.

## Ветки

- `dev` — разработка; pull request'ы направляйте сюда;
- `master` — текущая публичная версия;
- `stable` — последний стабильный релиз, отмечен тегом `vX.Y.Z`.

## Требования к изменениям

CI проверяет то же, что ниже; локально прогоните до отправки:

```bash
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
```

Изменения доставки через брокер проверяются на живом NATS с JetStream:

```bash
nats-server -js &
TRUST_MESSAGE_TEST_NATS_URL=nats://127.0.0.1:4222 \
TRUST_MESSAGE_TEST_NATS_BIN=nats-server \
  cargo test --test jetstream_delivery -- --ignored --test-threads=1
```

- Новое поведение покрыто тестами. CI требует не меньше 70% покрытия на
  добавленных строках `src/` (`scripts/coverage-gate.py`).
- Изменения схемы проходят `buf lint` и `buf breaking`. Номера полей не
  переиспользуются, удалённые поля помечаются `reserved`.
- Новое поле конфигурации в `src/config.rs` — с `///`-комментарием: имя
  переменной окружения, единица измерения, значение по умолчанию.
- Комментарии объясняют неочевидное «почему», а не пересказывают код.
- Никаких секретов, адресов боевых хостов и персональных данных в коде,
  тестах и логах.

## Сообщения коммитов

Формат `тип(область): описание`, например `fix(delivery): …`,
`feat(push): …`, `docs: …`. В теле — что изменилось и почему.
